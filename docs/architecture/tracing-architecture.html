Agent Tracing 系统架构

SDK 上报客户端工具 Span，网关独立记录审计。Tracing 核对 call_id 和追踪上下文，匹配后在调用树中展示同一个工具节点。

查看 V1 数据结构与 ER 图

V1 数据结构

下图和建表草案描述 Tracing 的 MySQL 投影。网关审计与 Outbox 仍在执行侧。所有表的标识范围由 tenant_id、environment_id、project_id 组成。ER 图省略重复的范围列，物理键和跨表关联均包含这些列。

会话与 SDK 遥测

PK 为主键，FK 为外键，UQ 为唯一键。Span 的父节点和 Link 的目标允许迟到。它们按已验证范围解析，不要求目标行先写入。

网关审计投影

只有通过校验的 SDK 工具 Span 才会补充同一个网关工具节点。deletion_marks 独立保存，清理 Trace 或 Session 后仍可拒绝重放。

字段、键与索引

三列归属键统一为 VARBINARY(64) NOT NULL。平台及可信目录的不透明 ID 采用原有等值语义，超长值拒绝。Trace 和 Span ID 分别为 16 与 8 字节。业务时间使用 UTC DATETIME(6)，OTLP 时间保持 Unix 纳秒。JSON 查询响应将大整数时间原值编码成十进制字符串。

sessions · 会话列表及可信会话归属

Session 按可信入口命名空间解析。显示名、MCP 协议 Session ID 和客户端自报身份无需进入主键。

spans · 不可变的已归一化 OTLP Span

网关事件契约

内部消息使用版本 1。所有事件携带作用域、已验签的 Trace 绑定与登记时间、Session 与轮次、可信调用元数据、调用 ID、事实源身份、事件 ID、修订号和发生时间。稳定的公共字段包含归属、Trace 绑定、call_id、受理时间、工具与操作 ID。尚缺的身份或证据引用由拥有该字段的事实源补齐。状态快照按以下流分开递增。

事件事实源与修订范围事件特有字段
initial_decision网关 · call_id 的初始决策决策、原因码、主要策略 ID/版本、证据引用
recheck网关 · call_id 的复验复验决策、原因码、主要策略 ID/版本、证据引用
confirmation确认服务 · confirmation_id当前状态、确认人、截止和动作时间、保留期限、证据引用
attempt执行器 · call_id + attempt_id尝试序号、当前结果、起止、下游请求、证据引用、对账保留期限

stream_key 使用事件类型与表中对象 ID 的长度前缀编码。事件 ID 负责重放去重。同一发布者的相同流与修订只接受相同规范化事实。每条流绑定跨实例稳定的逻辑发布者，服务身份须被授权代该发布者发送事件。不同事实源的修订号独立比较。

入库、合并与查询规则

  1. OTLP。 每个 exporter 的工作负载身份绑定单一租户、环境和项目，批次可以混合该范围的多条 Trace。在事务中校验可信登记、接收截止与生产者权限。按 Trace 顺序锁定登记行后检查父子结构，对允许字段和 Links 生成稳定摘要，批量插入并核对重复键。等价重试计为成功，冲突保留先前记录。只用已接受的行更新会话和 Trace，提交后再回 OTLP 成功。事务结果不明时按可重试错误处理。
  2. Outbox。 校验事实源与事件类型，锁定对应 Trace 并写入审计历史和快照。同一事件重放不改变记录。较旧修订进入历史，最新快照由对应流的较大修订更新。确认、尝试和复验各自维护状态。MySQL 提交后才确认 Outbox。未知版本和结构错误进入执行侧诊断，保留来源及原因码。
  3. 工具节点。 对齐归属、trace_id、agent_id 和 call_id，再比较 inbound_sdk_span_id = spans.span_id。匹配后使用网关节点 ID，沿 SDK Span 的 parent_span_id 挂树并补客户端耗时。SDK 或审计先到都能展示。两边匹配后用同一节点计数，只有 SDK 时按客户端观测展示，工具路径来自受控枚举。幂等重试即使收到原 call_id，也要匹配网关记录的原入站 Span ID，否则继续显示为独立客户端尝试。
  4. 状态与授权。 网关初始决策、最新复验、确认和最新执行尝试分别保留。阻断或拒绝且有证据表明未尝试时显示未执行。缺少结果时显示未知。所有跨表读取同时匹配归属与对象 ID，授权后才组树、计算 Session 结果及可见调用数。节点使用 span: 或 tool: 开头的独立 ID，SDK 已匹配时在本 Trace 内解析到对应的工具主节点。无权读取时使用统一的不可用响应。
  5. 留存。 基础到期从可信原始登记起算 30 天。只对清理前已消费到的确认和对账事件，按可信的有限 hold_until 延长留存。到期后收到的事件仍可在网关审计域按调用 ID 查阅。写入与清理使用同样的归属及对象锁顺序，将删除标记与删除写在同一事务。重放遵守原始到期和删除标记，恢复时先恢复独立保留的删除增量。

应用层校验字节 ID、允许字段、关系和授权组合。建表草案用于评审及本地验证，主键、类型、索引与约束可直接在 MySQL 8.4 验证。

CREATE TABLE sessions (
  tenant_id VARBINARY(64) NOT NULL,
  environment_id VARBINARY(64) NOT NULL,
  project_id VARBINARY(64) NOT NULL,
  session_id VARBINARY(64) NOT NULL,
  root_agent_id VARBINARY(64) NOT NULL,
  initiator_kind ENUM('user','workload','unknown') NOT NULL DEFAULT 'unknown',
  initiator_id VARBINARY(64) NULL,
  started_at DATETIME(6) NOT NULL,
  last_activity_at DATETIME(6) NOT NULL,
  PRIMARY KEY (tenant_id, environment_id, project_id, session_id),
  KEY ix_session_start (tenant_id, environment_id, project_id, started_at DESC, session_id DESC),
  KEY ix_session_agent (tenant_id, environment_id, project_id, root_agent_id, started_at DESC, session_id DESC)
) ENGINE=InnoDB;

CREATE TABLE traces (
  tenant_id VARBINARY(64) NOT NULL,
  environment_id VARBINARY(64) NOT NULL,
  project_id VARBINARY(64) NOT NULL,
  trace_id BINARY(16) NOT NULL,
  session_id VARBINARY(64) NOT NULL,
  run_kind ENUM('turn','autonomous','gateway_call') NOT NULL,
  run_key VARBINARY(64) NOT NULL,
  task_id VARBINARY(64) NULL,
  correlation_id VARBINARY(64) NULL,
  registered_at DATETIME(6) NOT NULL,
  sdk_root_span_id BINARY(8) NULL,
  sdk_root_producer_id VARBINARY(64) NULL,
  sdk_accept_until DATETIME(6) NULL,
  run_state ENUM('unknown','running','completed','failed','cancelled') NOT NULL DEFAULT 'unknown',
  observed_start_ns BIGINT UNSIGNED NULL,
  observed_end_ns BIGINT UNSIGNED NULL,
  expires_at DATETIME(6) NOT NULL,
  PRIMARY KEY (tenant_id, environment_id, project_id, trace_id),
  CONSTRAINT fk_trace_session FOREIGN KEY (tenant_id, environment_id, project_id, session_id) REFERENCES sessions (tenant_id, environment_id, project_id, session_id) ON DELETE CASCADE,
  UNIQUE KEY uk_trace_run (tenant_id, environment_id, project_id, session_id, run_kind, run_key),
  KEY ix_trace_session (tenant_id, environment_id, project_id, session_id, registered_at, trace_id),
  KEY ix_trace_expiry (expires_at),
  CHECK ((sdk_root_span_id IS NULL) = (sdk_accept_until IS NULL)),
  CHECK ((sdk_root_span_id IS NULL) = (sdk_root_producer_id IS NULL))
) ENGINE=InnoDB;

CREATE TABLE trace_producers (

  revoked_at DATETIME(6) NULL,
  PRIMARY KEY (tenant_id, environment_id, project_id, trace_id, producer_id, agent_id),
  CONSTRAINT fk_producer_trace FOREIGN KEY (tenant_id, environment_id, project_id, trace_id) REFERENCES traces (tenant_id, environment_id, project_id, trace_id) ON DELETE CASCADE
) ENGINE=InnoDB;

CREATE TABLE spans (
  tenant_id VARBINARY(64) NOT NULL,
  environment_id VARBINARY(64) NOT NULL,
  project_id VARBINARY(64) NOT NULL,
  trace_id BINARY(16) NOT NULL,
  span_id BINARY(8) NOT NULL,
  parent_span_id BINARY(8) NULL,
  producer_id VARBINARY(64) NOT NULL,
  agent_id VARBINARY(64) NOT NULL,
  kind ENUM('run','agent','llm','tool_client') NOT NULL,
  start_ns BIGINT UNSIGNED NOT NULL,
  end_ns BIGINT UNSIGNED NOT NULL,
  status ENUM('unset','ok','error') NOT NULL DEFAULT 'unset',
  run_outcome ENUM('completed','failed','cancelled') NULL,
  tool_id VARBINARY(64) NULL,
  tool_route ENUM('gateway','local','direct') NULL,
  client_call_id VARBINARY(64) NULL,
  client_result ENUM('response','timeout','error','cancelled') NULL,
  response_code SMALLINT UNSIGNED NULL,
  error_code VARCHAR(32) CHARACTER SET ascii COLLATE ascii_bin NULL,
  model_id VARBINARY(64) NULL,
  input_tokens INT UNSIGNED NULL,
  output_tokens INT UNSIGNED NULL,
  max_output_tokens INT UNSIGNED NULL,
  temperature DECIMAL(6,4) NULL,
  received_at DATETIME(6) NOT NULL,
  metadata_hash BINARY(32) NOT NULL,
  PRIMARY KEY (tenant_id, environment_id, project_id, trace_id, span_id),
  CONSTRAINT fk_span_trace FOREIGN KEY (tenant_id, environment_id, project_id, trace_id) REFERENCES traces (tenant_id, environment_id, project_id, trace_id) ON DELETE CASCADE,
  KEY ix_span_timeline (tenant_id, environment_id, project_id, trace_id, start_ns, span_id),
  KEY ix_span_parent (tenant_id, environment_id, project_id, trace_id, parent_span_id, span_id),
  CHECK (end_ns >= start_ns),
  CHECK (parent_span_id IS NULL OR parent_span_id <> span_id),
  CHECK (kind = 'run' OR run_outcome IS NULL),
  CHECK ((kind = 'tool_client') = (tool_route IS NOT NULL)),
  CHECK (client_call_id IS NULL OR (tool_route IS NOT NULL AND tool_route = 'gateway'))
) ENGINE=InnoDB;

CREATE TABLE audit_events (
  tenant_id VARBINARY(64) NOT NULL,
  environment_id VARBINARY(64) NOT NULL,
  project_id VARBINARY(64) NOT NULL,
  source_role ENUM('gateway','confirmation','executor') NOT NULL,
  source_id VARBINARY(64) NOT NULL,
  event_id VARBINARY(64) NOT NULL,
  call_id VARBINARY(64) NOT NULL,
  stream_key VARBINARY(160) NOT NULL,
  revision BIGINT UNSIGNED NOT NULL,
  event_kind ENUM('initial_decision','recheck','confirmation','attempt') NOT NULL,
  confirmation_id VARBINARY(64) NULL,
  attempt_id VARBINARY(64) NULL,
  decision ENUM('allowed','blocked','denied','confirmation_required') NULL,
  confirmation_state ENUM('pending','approved','denied','expired') NULL,
  execution_state ENUM('executing','succeeded','failed','unknown') NULL,
  confirmation_actor_id VARBINARY(64) NULL,
  confirmation_deadline_at DATETIME(6) NULL,
  confirmation_action_at DATETIME(6) NULL,
  attempt_no INT UNSIGNED NULL,
  attempt_started_at DATETIME(6) NULL,
  attempt_finished_at DATETIME(6) NULL,
  downstream_request_id VARBINARY(64) NULL,
  downstream_actor_id VARBINARY(64) NULL,
  hold_until DATETIME(6) NULL,
  policy_id VARBINARY(64) NULL,
  policy_version VARBINARY(64) NULL,
  reason_code VARCHAR(32) CHARACTER SET ascii COLLATE ascii_bin NULL,
  evidence_ref_id VARBINARY(64) NULL,
  schema_version SMALLINT UNSIGNED NOT NULL,
  occurred_at DATETIME(6) NOT NULL,
  received_at DATETIME(6) NOT NULL,
  event_hash BINARY(32) NOT NULL,
  PRIMARY KEY (tenant_id, environment_id, project_id, source_role, source_id, event_id),
  CONSTRAINT fk_event_call FOREIGN KEY (tenant_id, environment_id, project_id, call_id) REFERENCES tool_calls (tenant_id, environment_id, project_id, call_id) ON DELETE CASCADE,
  UNIQUE KEY uk_event_revision (tenant_id, environment_id, project_id, source_role, source_id, stream_key, revision),
  KEY ix_event_history (tenant_id, environment_id, project_id, call_id, occurred_at, source_role, source_id, event_id),
  CHECK (
      (source_role = 'gateway' AND event_kind IN ('initial_decision','recheck')
        AND decision IS NOT NULL AND confirmation_state IS NULL AND execution_state IS NULL
        AND confirmation_id IS NULL AND attempt_id IS NULL)
      OR (source_role = 'confirmation' AND event_kind = 'confirmation'
        AND decision IS NULL AND confirmation_state IS NOT NULL AND execution_state IS NULL
        AND confirmation_id IS NOT NULL AND attempt_id IS NULL)
      OR (source_role = 'executor' AND event_kind = 'attempt'
        AND decision IS NULL AND confirmation_state IS NULL AND execution_state IS NOT NULL
        AND confirmation_id IS NULL AND attempt_id IS NOT NULL)
    )
) ENGINE=InnoDB;

CREATE TABLE deletion_marks (

  environment_id VARBINARY(64) NOT NULL,
  project_id VARBINARY(64) NOT NULL,
  object_kind ENUM('trace','session') NOT NULL,

  PRIMARY KEY (tenant_id, environment_id, project_id, object_kind, object_id),
  KEY ix_delete_expiry (retain_until),
  CHECK (object_kind <> 'trace' OR OCTET_LENGTH(object_id) = 16),
  CHECK (retain_until > deleted_at)
) ENGINE=InnoDB;
